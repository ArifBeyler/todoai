# 1 Haftalik Pilot Olcum Cercevesi

## Hedef

Skill setinin gelistirme hizi, kod kalitesi, test kapsami ve guvenlige etkisini olcmek.

## Baslangic Tarihi

- Manuel giris: YYYY-MM-DD

## KPI'lar

1. Hiz
   - Gorev tamamlama suresi (ortalama)
   - Baslangic referansi: son 5 benzer gorev

2. Kalite
   - PR geri bildirim sayisi
   - Tekrar acilan bug sayisi

3. Test
   - Eklenen test adedi
   - Kritik akis kapsama durumu (var/yok)

4. Guvenlik
   - Engellenen riskli komut adedi
   - Gozlenen guvenlik acigi/regresyon adedi

## Skill Bazli Etki Notu

- `supabase/postgres-best-practices`: sorgu/migration kalitesi
- `openai/security-best-practices`: guvenlik kontrol kapsamı
- `openai/playwright`: kritik akislarda regresyon azaltma
- `getsentry/find-bugs`: hatalari erken yakalama
- `vercel-labs/react-best-practices`: component ve state duzeni
- `vercel-labs/next-best-practices`: web katmaninda mimari tutarlilik
- `expo/expo-app-design`: mobil UX tutarliligi
- `callstackincubator/react-native-best-practices`: RN performans ve stabilite

## Kabul Kriteri

- Hizde en az %10 iyilesme veya
- PR geri bildirimlerinde belirgin azalma veya
- Kritik regresyonda gozle gorulur dusus

Bu kriterlerden en az ikisi saglanmali.
