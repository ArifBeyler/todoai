# Cursor Skills - Dayframe

Bu klasor, projede kullanilacak secili skill'leri tek yerde toplar.
Amac, cok fazla skill yerine az ve etkili bir set ile hiz, kalite, test ve guvenligi birlikte iyilestirmektir.

## Baslangic Politikasi

- En fazla 8 aktif skill.
- Her skill "ne zaman kullanilir" net olmalı.
- Her skill icin guvenlik kontrolu zorunlu.
- 1 haftalik pilot sonunda etkisiz skill kaldirilir.

## Klasorler

- `skill-catalog/SHORTLIST.md`: aktif shortlist ve kullanim amaci
- `_shared/ADOPTION_WORKFLOW.md`: ekleme/degerlendirme adimlari
- `_shared/PILOT_METRICS.md`: 1 haftalik olcum ve kabul kriterleri
- `*/SKILL.md`: her skill icin proje-ozel kullanim sozlesmesi

## Not

Bu proje `Expo + React Native + Supabase` oldugu icin, React/Next skill'leri "web katmaninda" ve genel React prensiplerinde kullanilir.
