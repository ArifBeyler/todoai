React Native tarafinda performans, stabilite ve platform uyumunu iyilestirmek.

## Ne Zaman Kullanilir

- Liste/animasyon performansi sorunlarinda

- Cihazlar arasi davranis farklarini azaltirken

- Gerekmedikce erken optimizasyon yapma, once olc.
- Buyuk ekranlarda component maliyetini azalt.
- Kritik akislar iOS/Android parity kontrolunden gecsin.
