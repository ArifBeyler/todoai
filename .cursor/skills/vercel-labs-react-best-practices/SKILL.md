# vercel-labs/react-best-practices

## Amac

React component mimarisi, state yonetimi ve okunabilirligi iyilestirmek.

## Ne Zaman Kullanilir

- Yeni component dizayni yaparken
- Buyuyen component'i parcaya bolerken
- Gereksiz rerender kaynakli sorunlarda

## Proje Kurallari

- Erken return ve net branch akisi kullan.
- Tek sorumluluk prensibine gore component ayir.
- Props ve state adlarini acik ve tutarli sec.

## Kapsam

- React Native tarafinda da ortak React prensipleri icin kullanilir.
