# vercel-labs/next-best-practices

## Amac

Web/Next.js katmaninda route, data-fetching ve render stratejilerini dogru uygulamak.

## Ne Zaman Kullanilir

- Next.js sayfa/route gelistirirken
- SSR/ISR/CSR stratejisi secerken
- API route ve cache davranisi belirlerken

## Proje Kurallari

- Bu skill sadece web/next katmani varsa kullanilir.
- Mobil (Expo) koduna dogrudan uygulanmaz.

## Not

Bu proje Expo agirlikli oldugu icin ikincil onceliktedir.
